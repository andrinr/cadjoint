API reference

Parameters and geometry

Scalar and vector parameters, and extraction of a tree’s parameters.

Parameters

Parameter types and helpers.

geometry.Parameter Base class for optimizable parameters.
geometry.Scalar Scalar parameter (radius, distance, angle, scale, strength, etc.).
geometry.Vector 3D vector parameter (position, offset, direction, size).
geometry.Vector2 2D vector parameter (sketch points, planar offsets, profile vertices).
geometry.as_parameter Convert a raw value to a Parameter object automatically.
geometry.deduplicate_params Deduplicate parameters by identity, using param.name as canonical key.

Parameter extraction

Read free and fixed parameters from a tree; write values back.

extract_parameters Extract parameters from a Fluent tree.
apply_parameters Write solved/optimized values back into a tree’s free parameters.

Sketches and construction

Sketch planes, 2D profiles, features that generate solids, and face references.

Sketches

Work planes and closed polygon profiles.

construction.SketchPlane A work plane the sketch entities live on.
construction.PolygonProfile Closed polygon profile in a sketch plane — a construction-tree node.

Features

Extrude, revolve and loft a profile into a solid.

construction.extrude Extrude a 2D profile into a solid SDF.
construction.revolve Revolve a 2D profile around its sketch plane’s Y axis into a solid SDF.
construction.loft Loft between two 2D profiles into a solid SDF.
construction.Solid Factories creating a primitive and its construction mirror at once.
construction.ConstructionPrimitive A primitive with an editable placement, mirroring the SDF it generates.

Face references

Faces and axes of generated solids, used to place sketch planes.

construction.Face One analytic planar face of a construction feature.
construction.FaceSet The analytic faces of one feature, built on first use.
construction.Feature The record a generator leaves on the profiles it consumed.
construction.Axis A feature’s axis of revolution, exposed as a reusable reference.

Constraints

Constraint types, the constraint solver, and degree-of-freedom analysis.

Constraint types

One class per geometric relation.

constraints.Constraint Base class for geometric constraints.
constraints.DistanceConstraint Constraint that fixes the distance between two points/vectors.
constraints.AngleConstraint Constraint that fixes the angle between two vectors.
constraints.HorizontalConstraint Constraint that forces two sketch points onto a horizontal line.
constraints.VerticalConstraint Constraint that forces two sketch points onto a vertical line.
constraints.CoincidentConstraint Constraint that forces two sketch points to coincide.
constraints.FixedConstraint Constraint that anchors a free parameter to a fixed target value.
constraints.EqualLengthConstraint Constraint that forces two sketch edges to have equal length.
constraints.PointOnLineConstraint Constraint that forces a sketch point onto the infinite line through two points.
constraints.ParallelConstraint Constraint that forces two vectors to be parallel.
constraints.PerpendicularConstraint Constraint that forces two vectors to be perpendicular.
constraints.ParallelEdgesConstraint Constraint that forces two sketch edges to be parallel.
constraints.PerpendicularEdgesConstraint Constraint that forces two sketch edges to be perpendicular.

Solving and projection

Solve constraints and project parameters onto the constraint manifold or bounds.

solve_constraints Solve geometric constraints attached to a scene’s free parameters.
constraints.satisfy_constraints Project a construction/SDF tree onto its attached constraints in place.
constraints.constraint_residuals Evaluate the constraint residuals at free_params.
constraints.project_to_manifold Project free_params onto the constraint manifold via Newton correction(s).
constraints.make_manifold_projection Return an optax transform that projects params onto the constraint manifold.
constraints.project_bounds Clamp free_params to per-parameter bounds declared in metadata.
constraints.make_bounds_projection Return an optax transform that clamps params to their declared bounds.

Degrees of freedom

Residuals, parameter vectors and null-space maps.

constraints.all_parameters Return a deduplicated list of all parameters referenced by constraints.
constraints.total_dof_reduction Return the total number of DOF removed by a list of constraints.
constraints.build_residual_fn Build a flat residual function over all constraints.
constraints.compute_param_vector Build the initial flat parameter vector from an ordered params dict.
constraints.unpack_param_vector Inverse of compute_param_vector: split a flat array back into named values.
constraints.null_space Null-space projection and DOF analysis for constrained parameter systems.
constraints.NullSpaceMap Null-space projection matrix that operates directly on parameter dicts.

Solids

SDF primitives, booleans, transforms, patterns and measures.

Base class

Base class of all SDF nodes.

SDF Abstract base class for Signed Distance Functions.

Primitives

Standard shapes and the polygon solids produced by construction features.

sdf.Primitive Base class for primitive SDFs (leaf nodes in the SDF tree).
sdf.Box Axis-aligned box centered at origin.
sdf.RoundBox Box with rounded edges centered at origin.
sdf.Sphere Sphere centered at origin with given radius.
sdf.Cylinder Cylinder along Z-axis centered at origin.
sdf.Capsule Capsule (cylinder with spherical caps) along Z-axis.
sdf.Torus Torus in XY plane centered at origin.
sdf.Plane Infinite horizontal plane at y = height.
sdf.primitives.ExtrudedPolygon Solid formed by extruding a polygon profile along the local Z axis.
sdf.primitives.RevolvedPolygon Solid of revolution: a polygon profile revolved around the local Y axis.
sdf.primitives.LoftedPolygon Solid lofted between two polygon profiles along the local Z axis.
sdf.primitives.polygon_sdf_2d Exact signed distance from 2D point(s) to a simple polygon.

Booleans

Union, intersection, difference, xor and smooth blends.

sdf.Union Union of two or more SDFs (combines all shapes).
sdf.Intersection Intersection of two or more SDFs (only overlapping region).
sdf.Difference Difference of SDFs (subtract all subsequent from first).
sdf.Xor XOR of two SDFs (symmetric difference).
sdf.BooleanOp Base class for boolean operation SDFs.
sdf.union Union boolean operation.
sdf.intersection Intersection boolean operation.
sdf.difference Difference boolean operation.
sdf.xor XOR boolean operation.
sdf.smooth_min Smooth minimum function for blending SDFs (Inigo Quilez’s version).
sdf.smooth_max Smooth maximum function for blending SDFs.

Transforms

Affine transforms, deformations and field operations.

sdf.Translate Translate an SDF by a vector offset.
sdf.Rotate Rotate an SDF around an axis.
sdf.Scale Scale an SDF component-wise.
sdf.Twist Twist deformation around an arbitrary axis.
sdf.Shell Hollow shell of a shape’s surface: \|f(p)\| - thickness/2.
sdf.Offset Offset (grow/shrink) a shape’s surface: f(p) - distance.
sdf.Mirror Mirror a shape across a plane by reflecting the query point.
sdf.shell Hollow shell of shape’s surface with the given total thickness.
sdf.offset Grow (positive) or shrink (negative) shape by distance.
sdf.mirror Mirror image of shape across a plane.

Patterns

Linear and polar patterns.

sdf.LinearPattern Union of count copies translated along a direction.
sdf.PolarPattern Union of count copies rotated evenly around an axis.
sdf.linear_pattern count copies of shape spaced along direction.
sdf.polar_pattern count copies of shape rotated evenly around an axis.

Measure

Volume and mass.

sdf.volume Differentiable volume estimation for SDFs.
sdf.material_mass Estimate the mass of an SDF from its material field, as a JAX scalar.

Functionalize and parametrization

Convert solids and scenes to pure functions of their parameters; reparametrize for optimization.

Functionalize

SDF trees and scenes as pure functions of parameter dictionaries.

functionalize Compile parameterized SDF trees to pure JAX functions.
functionalize_scene Compile a geometry SDF tree to pure (sdf, material_fn) closures.
functionalize.functionalize_parametric Compile an SDF to a function whose parameters are arguments.
functionalize.functionalize_scene_parametric Compile a scene so its parameters are arguments, not literals.

Parametrization

Unconstrained reparametrization and parameter scaling.

to_unconstrained Map constrained free_params to an unconstrained dict.
to_constrained Map unconstrained params back to constrained space.
compute_param_scales Compute per-parameter normalization scales.
normalize Divide unconstrained params by their scales → O(1) optimizer space.
unnormalize Multiply normalized params by their scales → unconstrained space.
to_normalized to_unconstrained followed by normalize.
from_normalized unnormalize followed by to_constrained.

Meshing

Dual contouring from SDF to surface mesh, export and diagnostics.

Extraction

extract_mesh and its stages: grid sampling, edge crossings, QEF vertices, faces.

meshing.extract_mesh Extract a feature-preserving dual-contour mesh from an implicit field.
meshing.Mesh Dual-contour surface mesh.
meshing.GridSpec Regular sampling grid described by static Python values.
meshing.sample_grid Evaluate the field at every lattice vertex.
meshing.find_crossing_edges Find every lattice edge whose endpoints lie on opposite sides of level.
meshing.CrossingEdges Lattice edges whose endpoint field values straddle the isovalue.
meshing.edge_hermite_data Locate the surface crossing on every edge and evaluate its gradient.
meshing.HermiteData Surface crossings on grid edges with field gradients.
meshing.detect_edges Sample, detect crossing edges, and refine Hermite data in one call.
meshing.qef_vertices Place one vertex per active cell from its Hermite tangent planes.
meshing.sharp_qef_vertices Place vertices with a rank-revealing QEF that lands exactly on features.
meshing.dual_faces Connect cell vertices with one oriented quad per crossing edge.

Sharp features

Face, crease and corner classification; active CSG branches.

meshing.classify_feature_cells Classify active cells as face, crease, or corner from normal spread.
meshing.FeatureCells Per-cell feature classification.
meshing.cell_edge_incidence Group crossing edges by the grid cells they border.
meshing.manifold_cell_incidence Group crossing edges by cell and by inside-corner component.
meshing.CellIncidence Mapping from active cells to the crossing edges on their boundary.
meshing.feature_cell_links Link feature cells that are lattice neighbors (diagonals included).
meshing.active_branches Report which child field a hard CSG min/max selects per point.
meshing.detect_branch_changes Mark cells whose incident Hermite samples disagree on the active branch.
meshing.exact_feature_mask Mark adjacencies whose endpoint signatures differ.
meshing.ScenePatchFields Per-leaf patch decomposition of a scene.
meshing.scene_patch_fields Collect world-frame patch fields for every Boolean leaf of a scene.
meshing.world_frame_leaves Maximal world-frame subtrees below the scene’s Boolean structure.
meshing.signature_function Build the pure (leaf_id, patch_id) signature function of a scene.
meshing.patch_signatures Label points with their (leaf_id, patch_id) surface signature.

Adaptive extraction and simplification

Sparse lattices, bounds fitting and simplification.

meshing.surface_cells Find every unit cell that may contain the level set, by octree descent.
meshing.sparse_crossing_edges Detect crossing edges without sampling the full lattice.
meshing.bounds.fit_bounds (origin, size) of a box around the part, found at its own scale.
meshing.bounds.boundary_inside Whether any lattice vertex on the grid’s six faces lies inside the part.
meshing.simplify_mesh Simplify a dual-contour mesh by error-bounded, feature-safe collapses.

Export and diagnostics

OBJ, STL and STEP export; mesh quality checks.

meshing.save_obj Write a Wavefront OBJ file with merged planar n-gon faces.
meshing.save_stl Write the mesh triangles as an STL file.
meshing.save_step Write a minimal faceted STEP AP214 boundary representation.
meshing.remove_slivers Weld coincident vertices and drop the triangles that collapse.
meshing.merge_planar_faces Merge coplanar mesh quads into large polygon faces.
meshing.mesh_report Bundle every diagnostic into one report.
meshing.surface_deviation Sampled one-sided deviation of the mesh from the implicit surface.
meshing.triangle_quality Triangle shape statistics: minimum angles, aspect ratios, degeneracy.
meshing.self_intersections Sampled self-intersection test over non-adjacent triangle pairs.

Simulation

Simulation meshes, studies, boundary conditions, node selections, material properties and solver backends.

Meshes

Simulation meshes and SDF-to-hex/tet meshing.

fem.SimMesh A declarable, named meshing intent — the scene program’s mesh object.
fem.HexMesh A HEX8 volume mesh extracted from an SDF.
fem.TetMesh A TET4/TET10 volume mesh whose boundary vertices are DC surface vertices.
fem.sdf_to_hex_mesh Extract a HEX8 volume mesh from an SDF on a regular grid.
fem.sdf_to_tet_mesh Extract the DC surface of sdf on grid and tet-mesh its inside.
fem.recompute_points Recompute hex-mesh vertex positions differentiably with frozen topology.
fem.recompute_tet_points Recompute tet-mesh vertex positions differentiably with frozen topology.
fem.project_points Newton-project points onto the SDF zero set along the field gradient.
fem.Discretization A discretized scene: what studies, the optimiser, the viewer and selections need.
fem.Surface The boundary a discretization shows and selects on.
fem.FaceGroup A batch of boundary faces tagged for boundary-condition selection.
fem.select_faces Select boundary faces whose center (and normal) satisfy a predicate.
fem.faces_from_nodes Boundary quads spanned by a node set (all four corners selected).
fem.tet_faces_from_nodes Boundary triangles all three of whose corners belong to nodes.

Mesh quality

Element quality metrics.

fem.scaled_jacobians Per-element scaled Jacobian quality metric of each hex.
fem.aspect_ratios Per-element edge aspect ratio of each hex.
fem.corner_tet_volumes Signed corner-tetrahedron volumes (determinants) of each hex.
fem.tet_aspect_ratios Longest-to-shortest edge ratio per tet, at least 1.
fem.tet_radius_ratios Normalized radius ratio 3 r_in / r_circ per tet, in (0, 1].

Studies

Thermal and elastic studies and their results.

fem.ThermalStudy Declarative steady-state heat conduction study.
fem.ElasticStudy Declarative small-strain linear elasticity study.
fem.SimulationResult One solved study: named, typed, inspectable, exportable.
fem.ThermalProblem Steady heat conduction: −∇·(k∇T) = q with conditions by selection.
fem.ElasticProblem Small-strain linear elasticity: clamped selections, tractions by selection.
